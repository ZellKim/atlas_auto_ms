# Scientific Reports Submission Guidelines — 상세 정리본

> 원문 페이지: Nature / Scientific Reports, “Submission guidelines”  
> URL: https://www.nature.com/srep/author-instructions/submission-guidelines  
> 확인일: 2026-05-15  
>
> 주의: 이 문서는 원문 웹페이지의 구조와 제출 요건을 빠짐없이 따라가며 정리한 **상세 요약/체크리스트**입니다. 원문 전체를 그대로 복제한 문서는 아닙니다.

---

## 1. 페이지 개요

Scientific Reports의 투고 지침은 원고 형식, 초록, 키워드, 본문 구성, 커버레터, 수정 원고, LaTeX 제출, 문체, Methods, References, 윤리 선언, 보충자료, 그림/표/방정식, 통계 지침, 화학·생물학 명명법, 물질 특성 분석, Registered Reports까지 다룬다.

---

## 2. Format of articles

Scientific Reports는 원저 연구를 주로 다음 두 형식으로 받는다.

- Article
- Registered Report

일반적으로 단어 수나 페이지 수의 엄격한 제한은 두지 않지만, 간결한 작성을 강하게 권장한다.

권장 기준:

- Article은 조판 기준 약 11쪽 이하가 이상적이다.
- 본문은 Abstract, Methods, References, Figure legends를 제외하고 4,500단어 이하가 권장된다.
- 제목은 20단어 이하가 권장된다.
- 제목은 논문의 핵심 메시지를 과학적으로 정확한 하나의 문장으로 설명해야 한다.
- 제목에 말장난이나 관용구를 쓰지 않는 것이 권장된다.
- 초록은 200단어 이하가 권장된다.
- 어떤 제한이 실제 필수 요건인지에 대해서는 별도 submission checklist를 확인해야 한다.

---

## 3. Abstract

초록 작성 원칙:

- 초록에는 참고문헌을 넣지 않는다.
- 초록은 해당 주제에 대한 일반적 소개와 주요 결과·의미를 짧고 비전문적인 방식으로 전달해야 한다.
- 초록은 비구조화 형식이어야 하며, 소제목이나 섹션 구분을 넣지 않는다.
- Scientific Reports는 graphical abstract를 지원하지 않는다.

---

## 4. Keywords

- 색인 목적의 키워드 또는 핵심 구문을 최대 6개까지 사용할 수 있다.
- 키워드는 제출 논문의 주요 내용을 대표해야 한다.

---

## 5. Manuscript

### 5.1 Title page

원고 텍스트 파일은 title page로 시작해야 한다.

Title page에는 다음이 포함되어야 한다.

- 제목
- 저자 소속
- 연락처 정보
- 교신저자를 별표로 표시

### 5.2 각 섹션의 배경 설명

각 섹션은 연구 배경을 확장하는 참고문헌 기반 소개 문장을 포함하는 것이 권장된다. Abstract와 일부 중복되는 것은 허용된다.

### 5.3 Large Language Models / AI 사용

- ChatGPT와 같은 LLM은 현재 Scientific Reports의 authorship criteria를 충족하지 않는다.
- 저자 자격은 연구에 대한 책임성과 연결되지만, LLM에는 그러한 책임성을 적용하기 어렵기 때문이다.
- LLM 사용은 Methods 섹션에 적절히 문서화해야 한다.
- Methods가 없는 형식이라면 적절한 대체 위치에 명시해야 한다.
- AI 관련 세부 정책은 Editorial Policy의 AI 섹션을 확인하고 준수해야 한다.

### 5.4 본문 구조

본문에는 특정한 강제 구조는 없지만, 많은 경우 다음 구조가 적합하다.

- Introduction
- Results  
  - 소제목 사용 가능
- Discussion  
  - 소제목 없이 작성하는 것을 권장
- Methods

### 5.5 본문 뒤에 포함할 항목

본문 뒤에는 일반적으로 다음을 둔다.

- References  
  - 60개 이하가 권장되지만 엄격하게 강제되지는 않음
- Acknowledgements  
  - 선택 사항
- Author contributions
- Data availability statement  
  - 필수
- Additional Information  
  - Competing Interests Statement 포함
- Figure legends  
  - figure당 350단어 이하
- Tables  
  - 표 하나는 한 페이지 이내

### 5.6 Footnotes

- Footnotes는 사용하지 않는다.

### 5.7 Page/line numbers

- Editorial Board Member와 reviewer에게 전달되는 자료에 페이지 번호나 줄 번호가 자동으로 들어가지 않는다.
- 평가와 피드백을 쉽게 하기 위해 원고에 페이지 번호와 줄 번호를 넣는 것이 권장된다.

### 5.8 Display items

- 캡션 없는 분자 구조 그림은 제한적으로 포함 가능하다.
- 필요한 경우 번호가 붙은 수식도 포함 가능하다.
- Figure와 table을 합친 display item은 최대 8개로 제한된다.
- 원고 길이에 맞춰 display item 수를 조절하는 것이 좋다.
- 2,000단어 이하의 Article은 figure/table을 4개 이하로 하는 것이 권장된다.
- Scheme은 사용하지 말고 figure로 제시해야 한다.

### 5.9 제출 시 필수 포함 자료

제출물에는 다음이 포함되어야 한다.

- Cover letter
- 개별 figure 파일
- 필요한 경우 Supplementary Information 파일

### 5.10 최초 제출 시 파일 구성

최초 제출, 즉 revised manuscript가 아닌 경우:

- 원고 텍스트와 figure를 하나의 파일로 통합할 수 있다.
- 통합 파일은 최대 3 MB까지 가능하다.
- Microsoft Word 형식이 선호된다.
- LaTeX 또는 PDF도 허용된다.
- Figure는 본문 적절한 위치에 삽입하거나 끝부분에 모아 둘 수 있다.

### 5.11 Supplementary Information

- Supplementary Information은 별도 파일 하나로 통합해 제출하는 것이 권장된다.
- 가능하면 PDF 형식이 선호된다.

### 5.12 LaTeX template

- Scientific Reports 형식 기준에 맞춘 Overleaf 제출 템플릿이 제공된다.

## 6. Cover letter

Cover letter에는 다음을 포함해야 한다.

- 교신저자의 소속 및 연락처
- 해당 연구가 Scientific Reports에 적합한 이유에 대한 간단한 설명
- 적합하다고 생각하는 reviewer의 이름과 연락처
- 심사에서 제외하고 싶은 reviewer의 이름
- 해당 연구에 대해 Scientific Reports Editorial Board Member와 사전에 논의한 적이 있는지 여부

---

## 7. Revised manuscripts

수정 원고는 텍스트 전체를 하나의 파일로 제출해야 한다.

허용 형식:

- Microsoft Word
- LaTeX

주의:

- 수정 원고의 article text는 PDF로 받지 않는다.

수정 원고 준비 요건:

- 원고 파일은 single-column text로 작성한다.
- 양쪽 정렬은 사용하지 않는다.
- 각 페이지 footer에 아라비아 숫자로 페이지 번호를 넣는다.
- 텍스트에는 기본 Computer Modern font를 사용한다.
- 그리스 문자는 symbols font를 사용한다.
- Figure는 개별 파일로 제출한다.
- Supplementary Information은 별도 파일 하나로 통합해 제출한다.
- Supplementary Information 파일 첫 페이지에는 원고 제목과 저자 목록을 포함한다.
- 원고 텍스트와 figure를 하나의 파일로 통합하지 않을 경우, 모든 텍스트 내용을 Word 또는 LaTeX의 별도 단일 파일로 제공한다.

---

## 8. TeX / LaTeX files

LaTeX 제출 시 가능한 방식:

- 표준 Article document class 또는 유사 class 사용
- wlscirep.cls 및 Overleaf 템플릿 사용

권장 사항:

- Graphic 처리를 위해 graphicx.sty 사용
- 인용은 숫자형 reference만 사용

BibTeX 관련 주의:

- 시스템은 .bib 파일을 받을 수 없다.
- BibTeX를 사용한 경우 .bbl 파일을 LaTeX supplementary file로 포함해야 한다.
- Overleaf에서 생성되는 zip에는 일반적으로 .bbl 파일이 자동 포함된다.
- 또는 reference source code를 원고 .tex 파일 내부에 포함해야 한다.
- 최종 제출 전 .tex 파일이 독립적으로 오류나 경고 없이 컴파일되는지 확인해야 한다.

## 9. Writing your manuscript

Scientific Reports의 독자층은 다양한 분야의 과학자로 구성되어 있으므로 명확한 의사소통이 중요하다.

작성 원칙:

- 전문 용어는 가능한 피한다.
- 전문 용어가 불가피하면 명확히 설명한다.
- 약어는 최소화한다.
- 표준 약어가 아닌 약어 사용을 특히 줄인다.
- 약어를 사용할 경우, 본문이나 legend에서 처음 등장할 때 전체 표현을 풀어쓴다.
- 연구의 배경, 근거, 주요 결론을 명확히 설명한다.
- 제목과 초록은 어떤 과학자라도 이해할 수 있는 언어로 작성한다.
- 제출 전 다른 전문 분야의 동료에게 원고를 읽혀 비전문 독자가 어려워할 개념이나 용어를 확인하는 것이 권장된다.

---

## 10. Copy editing services

- Scientific Reports는 production 과정에서 심층 copy editing을 제공하지 않는다.
- 원고의 영어 문장이나 가독성 개선이 필요하면 submission 전 또는 revision 단계에서 copy editing/language editing service 사용을 고려할 수 있다.
- Nature Research Editing Service와 American Journal Experts가 언급되어 있다.
- Scientific Reports 저자는 해당 서비스의 첫 의뢰에 대해 10% 할인 혜택을 받을 수 있다고 안내되어 있다.
- Editing service 이용 비용은 저자 부담이다.
- Editing service 이용이 peer review 선정이나 논문 accept를 보장하지 않는다.

---

## 11. Methods

### 11.1 일반 원칙

- Methods 설명에는 단어 수 제한을 두지 않는다.
- 다른 연구자가 연구를 재현할 수 있을 만큼 충분한 실험 및 특성 분석 정보를 포함해야 한다.

### 11.2 Methods에 포함할 사항

- 표준 protocol과 실험 절차 설명
- 실험 결과에 critical한 경우에만 reagent 또는 instrument의 commercial supplier 명시
- kit를 사용한 경우 kit의 출처 명시
- 새로운 화합물 합성 protocol
- 새로운 화합물은 systematic name을 사용하고, 실험 protocol 제목에는 굵은 아라비아 숫자를 부여하며 이후 해당 숫자로 지칭
- reagent 양은 가능한 괄호 안에 수치와 단위를 제시
- reagent와 solvent에는 표준 약어 사용
- reagent나 protocol이 야기할 수 있는 안전상 위험을 명확히 식별
- 각 protocol 끝에 isolated mass와 percent yield 보고

### 11.3 윤리 승인 문구

다음 연구는 Methods에 윤리 승인 statement가 필요하다.

- 살아 있는 척추동물 연구
- 고등 무척추동물 연구
- 인간 대상 연구
- 인간 샘플 연구

---

## 12. References

### 12.1 기본 원칙

- Scientific Reports는 reference를 copy edit하지 않는다.
- Reference는 전자 데이터베이스와 연결될 수 있으므로 정확히 format해야 한다.
- 표준 Nature referencing style을 사용한다.

### 12.2 Reference 형식 요건

Reference는 다음 기준을 따라야 한다.

- 본문 등장 순서대로 번호를 매긴다.
- 숫자형 reference를 사용한다.
- 대괄호 안에 표시한다.
- 하나의 번호에는 하나의 publication만 연결한다.
- 출판되었거나 accepted 상태인 논문 또는 dataset만 포함한다.
- 인정된 preprint server 또는 data repository의 자료를 포함할 수 있다.
- accepted paper의 preprint를 reference list에 포함할 경우, 원고와 함께 제출해야 한다.
- 출판된 conference abstract와 numbered patent는 포함 가능하다.
- Grant details와 acknowledgements는 reference에 포함하지 않는다.

### 12.3 BibTeX 관련

- .bib 파일은 허용되지 않는다.
- LaTeX 제출 시 reference는 .tex 내부에 포함하거나, Overleaf 템플릿 사용 시 생성된 .bbl 파일을 LaTeX supplementary file로 제출해야 한다.

### 12.4 Reference list 세부 형식

Reference list 작성 기준:

- 저자가 5명 이하이면 모든 저자를 기재한다.
- 저자가 6명 이상이면 첫 저자만 쓰고 et al.을 붙인다.
- 저자는 성을 먼저 쓰고, 쉼표 뒤에 이름 이니셜을 쓴다.
- 이름 이니셜에는 full stop을 붙인다.
- Article과 dataset 제목은 roman text로 쓴다.
- Article/dataset 제목은 첫 단어만 대문자로 시작하고, 인용 대상에 나온 제목을 그대로 따른다.
- 제목 끝에는 full stop을 붙인다.
- Book title은 italic으로 쓰고 주요 단어의 첫 글자를 대문자로 쓴다.
- Journal과 data repository 이름은 italic으로 쓰고 관용적 약어를 사용한다.
- Volume number는 bold로 쓰고 뒤에 쉼표를 붙인다.
- 필요한 경우 전체 page range 또는 article number를 제시한다.

### 12.5 Reference 예시 유형

원문은 다음 유형의 reference 예시를 제공한다.

- Printed journal article
- Online-only journal article
- 저자가 6명 이상인 논문
- Book 또는 book chapter
- Online material
- Preprint
- Blog post
- Dataset / figshare 자료

---

## 13. Acknowledgements

Acknowledgements 작성 원칙:

- 간결하게 작성한다.
- 익명 referee나 editor에 대한 감사는 포함하지 않는다.
- 과도한 찬사 표현은 피한다.
- Grant number나 contribution number는 언급할 수 있다.
- Medical writer, proof-reader, editor의 도움은 acknowledgement에 포함해야 한다.

---

## 14. Author contributions

- Author Contribution Statement를 제출해야 한다.
- 이는 Editorial and Publishing Policies의 Author responsibilities 섹션에 따라 작성한다.
- 교신저자로 제출한 저자는 review 과정의 주 연락 담당자가 되며 변경하지 않는 것이 원칙이다.
- 제출 시스템에 입력한 정보가 출판 시 source of truth로 사용된다.

---

## 15. Competing interests

- Competing interests statement를 반드시 제출해야 한다.
- 이해상충이 없으면 없다고 명시해야 한다.
- Statement는 명확하고 모호하지 않아야 한다.
- 각 contributing author별로 잠재적 competing interest 또는 그 부재를 설명해야 한다.
- 제출 시스템에 입력한 정보가 출판 시 source of truth로 사용된다.
- 원문은 “competing interests 없음” 선언 예시와 특정 저자의 funding, advisory board, stock ownership, consulting compensation 등을 포함하는 선언 예시를 제공한다.

---

## 16. Data availability

- 모든 제출 원고에는 Data Availability Statement가 필수다.
- 이 statement는 main text 끝, References 앞에 위치해야 한다.
- 구체적 요건은 Availability of materials and data 섹션을 참조해야 한다.

---

## 17. Ethics declarations

- 인간 참가자 또는 동물 대상 연구를 포함하는 경우, Methods 섹션에 적절한 ethics declaration을 포함해야 한다.

---

## 18. Approval for animal experiments

살아 있는 척추동물 또는 고등 무척추동물을 사용하는 실험의 경우 Methods에 다음을 포함해야 한다.

1. 실험을 승인한 기관 또는 licensing committee 식별
2. 관련된 명명된 guidelines와 regulations에 따라 모든 실험이 수행되었다는 확인

---

## 19. Approval for human experiments

인간 참가자 또는 인간 조직 샘플을 포함하는 실험의 경우 Methods에 다음을 포함해야 한다.

1. 실험을 승인한 기관 또는 licensing committee 식별
2. 관련된 명명된 guidelines와 regulations에 따라 모든 실험이 수행되었다는 확인
3. 모든 참가자 및/또는 법적 보호자로부터 informed consent를 받았다는 확인

---

## 20. Consent to participate / Consent to publish

주의 사항:

1. 연구 참가자의 이름과 기타 개인식별정보는 모든 text, figure, table, image에서 제거해야 한다.
2. 눈 또는 얼굴 부위를 색 막대, 도형, blur로 가리는 것은 적절한 익명화 방법으로 인정되지 않는다.
3. 참가자를 식별할 수 있는 정보나 이미지가 포함된 원고는, 해당 정보/이미지를 온라인 open access publication에 게재하는 데 대한 informed consent를 받았다는 statement를 Methods에 포함해야 한다.

## 21. Supplementary Information

### 21.1 제출 시점과 위치

- Supplementary Information은 원고와 함께 제출해야 한다.
- 그래야 peer review 과정에서 referee에게 함께 전달될 수 있다.
- main body에는 별도 appendix나 additional information을 넣지 않는다.
- 모든 supplementary material은 dedicated Supplementary Information file에 포함해야 한다.
- accepted manuscript와 함께 온라인에 게시된다.

### 21.2 출판 후 수정

- 출판 후 Supplementary Information 수정은 formal correction이 필요하므로 제출 전에 철저히 확인해야 한다.

### 21.3 “Data not shown” 지양

- “data not shown” 표현은 피한다.
- 대신 public repository에 데이터를 deposition하는 것이 권장된다.
- 논문 주장을 평가하는 데 필요한 데이터가 public repository에 없으면 Supplementary Information으로 제공해야 한다.

### 21.4 편집·교정 여부

- Supplementary Information은 저널에서 edit, typeset, proof하지 않는다.
- 처음 제출할 때부터 명확하고 간결하게 제시해야 한다.
- 본문과 같은 style 및 terminology를 유지해야 한다.

### 21.5 Supplementary Information 작성·인용·제출 지침

1. 여러 supplementary 자료를 하나의 composite file로 통합할 수 있다.
2. 큰 파일, 예를 들어 supplementary video, spreadsheet, data file 등은 별도 파일로 둘 수 있다.
3. 각 항목은 Supplementary Table, Figure, Video, Audio, Note, Data, Discussion, Equations, Methods 등으로 지정한다.
4. Supplementary Table과 Supplementary Figure는 “Supplementary Table S1”과 같이 번호를 붙인다.
5. 이 번호 체계는 본문 figure/table 번호와 분리해야 한다.
6. Supplementary Note 또는 Supplementary Methods는 번호를 붙이지 않으며, 제목은 선택 사항이다.
7. 본문에서 각 supplementary material을 적절한 위치에 언급해야 한다.
8. 언급할 때마다 “Supplementary”라는 단어를 포함해야 한다.
9. Supplementary figure의 개별 panel만 따로 지칭하지 않는다.
10. 원문은 Supplementary Table과 Supplementary Figure를 본문에서 언급하는 문장 예시를 제공한다.
11. 제출되는 모든 supplementary figure에는 짧은 제목과 legend를 포함해야 하며, 이는 파일 안에서 이미지 근처에 위치해야 한다.
12. 모든 supplementary table에는 제목이 있어야 한다.
13. 파일 크기는 가능한 작게 유지해야 하며, 최대 크기는 50 MB다.
14. Supplementary video는 표준 화면비인 4:3, 16:9, 21:9로 제공해야 한다.
15. 추가 질문은 Scientific Reports admin email로 문의하도록 안내되어 있다.

## 22. Figure legends

Figure legend 작성 원칙:

- 이어서 각 panel에 무엇이 표시되어 있는지 간략히 설명한다.
- 사용한 symbol은 순서대로 설명한다.
- Methods 세부사항은 가능한 줄인다.
- 각 figure legend는 총 350단어 이하로 작성한다.
- Figure legend 텍스트는 References 뒤에 번호 순서대로 제공한다.

- Microsoft Word의 equation editor로 만들 수 있다.

## 25. General figure guidelines

### 25.1 저작권과 출처

- 저작권이 있는 figure나 illustration을 출판하려면 필요한 허가를 저자가 받아야 한다.
- 다른 곳에 출판된 figure, 전문 photographer가 촬영한 사진도 포함된다.
- 인터넷에서 다운로드한 이미지는 적절한 permission 없이는 출판할 수 없다.
- 사용한 이미지의 출처를 명시해야 한다.
- 저자 또는 공동저자가 직접 그린 이미지는 acknowledgements에 언급해야 한다.
- Software 사용 시 software name, version number, URL을 명시한다.

### 25.2 Figure 번호와 통계 표시

- Figure는 본문 등장 순서대로 아라비아 숫자로 번호를 붙인다.
- 필요한 경우 error bar를 포함한다.
- Error analysis의 통계 처리 방법을 figure legend에 설명한다.

### 25.3 Scheme 금지

- Scheme은 사용하지 않는다.
- 화학 반응 sequence나 실험 절차는 caption이 있는 figure로 제출한다.
- 캡션 없는 chemical structure graphic은 제한적으로 본문에 포함할 수 있으며, 이름, 정의된 약어 또는 굵은 아라비아 숫자로 표시해야 한다.

### 25.4 Figure 스타일

- Figure lettering에는 Helvetica 같은 명확한 sans-serif 서체를 사용한다.
- 모든 figure에서 같은 서체와 같은 font size를 사용한다.
- Greek letters에는 symbols font를 사용한다.
- 모든 display item은 흰 배경을 사용한다.
- 과도한 박스, 불필요한 색, 장식 효과, 3D histogram 같은 시각적 과장을 피한다.
- 작은 차이를 부풀리기 위해 histogram의 y축을 자르지 않는다.
- 축소 후에도 label이 충분히 크고 대비가 있어야 한다.
- 최종 figure에서 가장 얇은 선은 1 point 이상이어야 한다.
- proof에는 figure가 포함되어 전달된다.

### 25.5 Figure 세부 규칙

- 여러 part로 나뉜 figure는 a, b, c 등 소문자 굵은 글자로 표시한다.
- Part label은 figure의 다른 글자와 같은 크기여야 한다.
- Figure lettering은 lower-case type을 사용하고, 각 label의 첫 글자만 대문자로 쓴다.
- 숫자와 단위 사이에는 공백 하나를 둔다.
- 단위는 SI nomenclature 또는 해당 분야의 일반 명명법을 따른다.
- 천 단위에는 쉼표를 사용한다.
- 특이한 단위나 약어는 legend에서 풀어 쓰거나 정의한다.
- Magnification factor보다는 scale bar를 사용한다.
- Scale bar 길이는 legend가 아니라 bar 자체에 표시한다.

### 25.6 Legend와 panel 구성

- Legend에서는 “open red triangles” 같은 말 설명보다 시각적 단서를 활용한다.
- 불필요한 figure를 피한다.
- 작은 table이나 histogram에 담을 수 있는 데이터는 본문에서 간단히 설명하는 것이 더 적절할 수 있다.
- 논리적으로 연결되지 않는 한 figure에 여러 panel을 넣지 않는다.
- Multipart figure의 각 panel은 전체 figure가 동일한 축소율로 줄어들 수 있도록 배치해야 한다.
- Essential detail이 보이는 가장 작은 크기로 재현될 수 있어야 한다.

## 27. Figures for publication

### 27.1 기본 파일 구성

- 완성된 각 figure를 별도 파일로 제출해야 한다.
- Multi-part/panel figure는 모든 sub-part, 예를 들어 a, b, c 등을 포함한 하나의 image file로 구성해야 한다.
- 각 panel을 따로 업로드하지 않는다.
- Editorial and Publishing Policies의 digital images integrity and standards를 확인해야 한다.
- 가능하면 original digital figure를 사용하는 것이 선호된다.
- 지침을 따르지 않으면 publication delay가 생길 수 있다.
- Springer Nature는 published maps와 institutional affiliations에 관한 jurisdictional claim에 대해 neutral하다고 명시한다.

### 27.2 Line art, graphs, charts, schematics

- Line art, graph, chart, schematic은 가능하면 vector format으로 제출한다.
- 예: EPS, AI
- Figure를 만든 application에서 직접 save/export하는 것이 좋다.
- Data point와 axis label이 명확히 보이도록 한다.

### 27.3 Photographic and bitmap images

- Photo와 bitmap image는 bitmap image format으로 제출한다.
- 예: TIFF, JPG, PSD
- TIFF 저장 시 파일 크기를 줄이기 위해 compression option을 선택한다.
- Word 또는 PowerPoint 파일 안에 배치된 image 형태로 제출하지 않는다.
- RGB 또는 CMYK 모두 가능하다.
- 저널은 image color mode를 변환하지 않는다.
- 기준을 충족하지 못하는 figure는 reproduction 품질이 떨어지고 high-resolution image 재제출로 인해 publication delay가 발생할 수 있다.

### 27.4 Chemical structures

- Chemical structure는 ChemDraw 또는 유사 프로그램으로 제작한다.
- 모든 chemical compound에는 본문 등장 순서대로 굵은 아라비아 숫자를 부여한다.
- Structure는 300 dpi RGB TIFF 파일로 export해 제출한다.

### 27.5 Stereo images

- Stereo diagram은 divergent wall-eyed viewing 방식으로 제시한다.
- 두 panel 사이 간격은 5.5 cm로 한다.
- 최종 accept 버전에서는 stereo image를 최종 page size로 제출한다.

## 28. Statistical guidelines

통계 검정을 포함한 논문은 다음을 명시해야 한다.

- 사용한 statistical test의 이름
- 각 statistical analysis의 n 값
- 관심 비교 대상
- 해당 test 사용 근거
- 정규성 등 test assumptions에 대한 논의
- 모든 test의 alpha level
- one-tailed인지 two-tailed인지
- 실제 P value  
  - 단순히 “significant” 또는 “P < 0.05”라고만 쓰면 안 됨

추가 원칙:

- 모든 P value가 어떤 statistical test에서 산출되었는지 명확히 해야 한다.
- “significant”라는 단어는 항상 P value와 함께 사용해야 한다.
- P value 없이 표현할 때는 “substantial”, “considerable” 등 다른 표현을 사용한다.
- Dataset은 descriptive statistics로 요약해야 한다.
- 각 dataset의 n 값, 중심 경향 측도, 변동성 측도를 명확히 표시한다.
- 중심 경향 예: mean, median
- 변동성 예: standard deviation, range
- 작은 dataset에서는 standard deviation 또는 standard error보다 range가 더 적절하다.
- Graph에는 명확히 label된 error bar를 포함한다.
- ± 뒤의 숫자가 s.e.m.인지 s.d.인지 반드시 명시한다.

### 28.1 자주 발생하는 세 가지 오류

1. **Multiple comparisons**
   - 하나의 dataset에서 여러 통계 비교를 할 경우, Type I error rate 증가를 막기 위해 alpha level을 어떻게 조정했는지 설명해야 한다.
   - 또는 여러 group에 적합한 test를 사용해야 한다.
   - 예: 여러 t-test 대신 ANOVA 사용

2. **Normal distribution**
   - 많은 statistical test는 데이터가 대략 정규분포를 따른다는 가정을 요구한다.
   - 이러한 test를 사용할 때는 정규성 검정을 어떻게 했는지 설명해야 한다.
   - 가정이 충족되지 않으면 non-parametric alternative를 사용해야 한다.

3. **Small sample size**
   - Sample size가 작을 때, 대략 10 미만일 때는 small sample에 적합한 test를 사용하거나 large-sample test 사용을 정당화해야 한다.

## 29. Chemical and biological nomenclature and abbreviations

- Molecular structure는 본문 등장 순서대로 굵은 아라비아 숫자로 식별한다.
- Main text 또는 figure에서 한 번 식별한 후에는 compound name, 정의된 abbreviation, 또는 굵은 아라비아 숫자 중 하나로 지칭할 수 있다.
- 단, 한 방식으로 일관되게 지칭해야 한다.
- Chemical compound와 biomolecule은 가능한 systematic nomenclature를 사용한다.
- IUPAC 명명법 사용이 권장된다.
- 표준 chemical/biological abbreviation을 사용한다.
- 비표준 또는 전문 abbreviation은 처음 등장할 때 정의한다.

## 30. Gene nomenclature

- Gene symbol에는 승인된 nomenclature를 사용해야 한다.
- Italicized full name보다 symbol을 사용한다.
- 예: titin이 아니라 Ttn
- 정확한 gene name과 symbol은 적절한 nomenclature database를 확인한다.
- Human gene symbol은 HGNC에서 확인할 수 있다.
- Mouse symbol은 The Jackson Laboratory에서 확인할 수 있다.
- 아직 승인되지 않은 proposed gene name은 publication 전에 적절한 nomenclature committee에 제출하여 승인받아야 한다.
- 여러 gene/protein 이름을 slash로 나열하는 방식은 피한다.
- Slash 표기는 ratio, complex, alternative name, different subunit 등으로 모호하게 해석될 수 있다.
- 하나의 이름을 일관되게 사용하고, 다른 이름은 처음 등장할 때 “also known as” 방식으로 제시한다.

## 31. Characterisation of chemical and biomolecular materials

Scientific Reports는 technically sound research를 출판하는 데 중점을 두며, 새로운 compound의 experimental methods와 characterisation에 대해 엄격한 기준을 적용한다.

### 31.1 기본 요건

- 원고에서 설명하는 각 new compound의 identity와 purity를 뒷받침할 충분한 데이터를 제공해야 한다.
- 연구 핵심에 중요한 known compound에 대해서도 source, identity, purity를 확인하는 statement를 제공해야 한다.
- 이는 purchased compound 또는 published method로 resynthesised compound인 경우에도 해당한다.

### 31.2 Chemical identity

Organic 및 organometallic compound의 chemical identity는 spectroscopic analysis로 확립해야 한다.

필요한 자료:

- 모든 new compound에 대한 1H NMR standard peak listing
- 모든 new compound에 대한 proton-decoupled 13C NMR standard peak listing
- 필요한 경우 31P NMR, 19F NMR 등 기타 NMR data
- New material의 경우 molecular weight identity를 뒷받침하는 mass spectral data
- HRMS data가 선호됨
- 적절한 경우 UV 또는 IR spectral data
- Crystalline material의 경우 melting-point range
- Chiral compound의 경우 specific rotation

Known compound:

- 자세한 procedure 대신 reference를 제공할 수 있다.
- 단, 기존 방법과 다르거나 개선된 protocol이면 상세 procedure가 필요할 수 있다.

### 31.3 Combinatorial compound libraries

- Combinatorial library preparation을 설명할 때는 library component의 다양한 panel에 대한 standard characterisation data를 포함해야 한다.

### 31.4 Biomolecular identity

새로운 biopolymeric material의 경우, 예를 들어 oligosaccharide, peptide, nucleic acid 등은 직접 NMR 구조 분석이 불가능할 수 있다. 이때는 다음 근거를 제공해야 한다.

- Sequence 기반 identity evidence
- 필요한 경우 mass spectral characterisation

### 31.5 Biological constructs

Plasmid, fusion protein, site-directed mutant 등 biological construct는 identity를 검증하는 자료가 필요하다.

가능한 자료:

- Sequencing data
- Functional data

이 자료는 manuscript text 또는 Methods에 포함한다.

### 31.6 Sample purity

- 각 new compound에 대한 sample purity evidence를 제공해야 한다.
- Purity analysis method는 compound class에 따라 달라진다.
- 대부분의 organic/organometallic compound는 high-field 1H NMR 또는 13C NMR로 purity를 입증할 수 있다.
- Small molecule에서는 elemental analysis가 권장되며, 허용 오차는 ±0.4%로 제시되어 있다.
- Small molecule 및 polymeric material의 purity 입증에는 GC, HPLC 등 chromatographic method나 electrophoretic analysis 같은 quantitative analytical method를 사용할 수 있다.

### 31.7 Spectral data

- New compound의 detailed spectral data는 Methods에 list form으로 제공한다.
- Spectrum image는 논문 핵심 결론과 직접 관련이 없는 한 일반적으로 manuscript figure로 출판되지 않는다.
- Key compound의 high-quality spectral data image는 Supplementary Information에 포함하는 것이 권장된다.
- NMR assignment는 multidimensional NMR 또는 decoupling experiment로 명확히 결정된 경우에만 integration value 뒤에 제시한다.
- Assignment가 어떻게 이루어졌는지는 general Methods에서 설명해야 한다.
- 원문은 melting point, TLC, optical rotation, 1H NMR, 13C NMR, IR, UV/Vis, HRMS, elemental analysis를 포함한 compound characterisation 예시 형식을 제공한다.

### 31.8 Crystallographic data for small molecules

New 3D small molecule structure를 crystallographic analysis로 보고하는 경우:

- .cif file을 포함해야 한다.
- Probability ellipsoid가 포함된 structural figure를 Supplementary Information으로 제공해야 한다.
- IUCR CheckCIF routine으로 확인해야 한다.
- CheckCIF output의 PDF copy를 제출해야 한다.
- 보고된 alert에 대한 justification도 함께 제출해야 한다.
- Small molecule crystallographic data는 Cambridge Structural Database에 제출해야 한다.
- Deposition number를 원고에 적절히 인용해야 한다.
- Publication 시점에는 full access가 제공되어야 한다.

### 31.9 Macromolecular structural data

새로운 macromolecular structure를 보고하는 원고는 다음을 포함해야 한다.

- Structural statistics와 refinement statistics를 요약한 table
- NMR 및 X-ray crystallography data table template 사용 가능
- Structural data의 품질 평가를 돕기 위해 다음 중 하나를 manuscript와 함께 제출
  - Crystallography paper: electron density map 일부의 stereo image
  - NMR paper: lowest energy structures의 중첩 stereo image, 대략 10개 이상
- Novel overall fold를 보고하는 경우 전체 structure의 stereo image도 제공해야 한다.
- 전체 구조는 backbone trace로 제시한다.

## 32. Registered Reports

Registered Reports는 original research article의 한 형식이다.

특징:

- Data collection과 analysis 전에 peer review를 받는다.
- Hypothesis-driven research에서 publication bias와 research bias를 줄이기 위한 형식이다.
- Exploratory, 즉 unregistered analysis와 우연히 발견된 결과를 보고할 유연성도 허용한다.
- Scientific Reports에 Registered Report를 제출하려는 경우 별도 detailed guidelines를 확인해야 한다.

## 34. 제출 전 핵심 체크리스트

### 34.1 원고 구조

- [ ] Title page 포함
- [ ] 교신저자 표시
- [ ] Introduction / Results / Discussion / Methods 구조 또는 연구에 맞는 합리적 구조
- [ ] References
- [ ] Acknowledgements, 필요한 경우
- [ ] Author contributions
- [ ] Data availability statement
- [ ] Additional Information 및 Competing Interests Statement
- [ ] Figure legends
- [ ] Tables

### 34.2 길이와 형식

- [ ] 제목 20단어 이하 권장
- [ ] Abstract 200단어 이하 권장
- [ ] Main text 4,500단어 이하 권장
- [ ] Article 11 typeset pages 이하 권장
- [ ] Display item 8개 이하
- [ ] 짧은 Article은 figure/table 4개 이하 권장
- [ ] Footnote 없음
- [ ] Page/line number 포함 권장

### 34.3 필수 선언

- [ ] Data Availability Statement
- [ ] Author Contribution Statement
- [ ] Competing Interests Statement
- [ ] 인간/동물 연구 시 ethics declaration
- [ ] 인간 대상/샘플 연구 시 informed consent
- [ ] 식별 가능한 참가자 정보/이미지 사용 시 consent to publish
- [ ] LLM/AI 사용 시 Methods 또는 적절한 위치에 문서화

### 34.4 파일 제출

- [ ] Cover letter
- [ ] Manuscript file
- [ ] 개별 figure file
- [ ] Supplementary Information file, 필요한 경우
- [ ] Revised manuscript는 PDF article text 불가
- [ ] LaTeX 사용 시 .bib 대신 .bbl 또는 .tex 내부 reference

### 34.5 통계

- [ ] Statistical test 이름 명시
- [ ] 각 분석의 n 값 명시
- [ ] 비교 대상 명시
- [ ] Test 선택 근거와 assumptions 설명
- [ ] Alpha level 명시
- [ ] One-tailed/two-tailed 여부 명시
- [ ] 실제 P value 제공
- [ ] Multiple comparisons 조정 설명
- [ ] Normality 확인 또는 non-parametric 대안 사용
- [ ] Small sample size에 맞는 test 또는 정당화
- [ ] Error bar 의미 명확히 표시
- [ ] ± 값이 s.e.m.인지 s.d.인지 명시

### 34.6 Figure / Table

- [ ] Figure permission 확보
- [ ] Image source 명시
- [ ] Software name/version/URL 명시
- [ ] Figure 번호 순서 확인
- [ ] Scheme을 figure로 전환
- [ ] Figure lettering 일관성 확인
- [ ] Axis truncation으로 차이를 과장하지 않음
- [ ] Scale bar 사용
- [ ] Publication용 figure는 개별 파일로 제출
- [ ] Multi-panel figure는 하나의 image file로 구성
- [ ] Table은 editable format으로 제출, image 사용 금지

### 34.7 Supplementary Information

- [ ] 본문이 아닌 dedicated Supplementary Information file에 포함
- [ ] 출판 후 formal correction 없이 수정이 어렵다는 점 확인
- [ ] “data not shown” 표현 제거
- [ ] 필요한 데이터는 repository 또는 Supplementary Information으로 제공
- [ ] Supplementary 항목 명명과 번호 체계 확인
- [ ] 본문에서 “Supplementary”라는 단어를 포함해 참조
- [ ] Supplementary figure에는 제목과 legend 포함
- [ ] Supplementary table에는 제목 포함
- [ ] 파일 크기 50 MB 이하
- [ ] Video 화면비 4:3, 16:9, 21:9

## 35. 연구자가 특히 주의할 포인트

1. **Data Availability Statement는 필수**이며 References 앞에 위치해야 한다.
2. **Competing Interests Statement는 모든 저자별로 명확해야 한다.**
3. **LLM 사용은 저자 자격으로 인정되지 않으며, 사용 사실은 Methods 등에 문서화해야 한다.**
4. **Revised manuscript는 article text를 PDF로 제출할 수 없다.**
5. **References는 Nature style을 따르며 .bib 파일은 허용되지 않는다.**
6. **통계 분석은 단순히 P < 0.05로 쓰면 부족하며, test명·n·비교·assumption·alpha·tail·실제 P value가 필요하다.**
7. **인간 대상 연구와 동물 연구는 Methods에 윤리 승인 및 관련 규정 준수 문구가 필요하다.**
8. **식별 가능한 참가자 이미지는 blur나 눈 가림만으로 익명화되지 않는다.**
9. **Supplementary Information은 출판 후 수정이 어렵기 때문에 제출 전 검토가 중요하다.**
10. **Figure는 저작권, 해상도, 파일 형식, panel 구성, lettering, scale bar, 통계 표시까지 모두 점검해야 한다.**
